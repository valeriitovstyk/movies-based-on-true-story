# Як оновлювати каталог

Фільми зберігаються окремо від сайту. Єдине джерело каталогу — `films.json` у цій папці. `index.html` більше не містить сотні записів і його не потрібно редагувати при звичайному оновленні списку.

## Звичайне оновлення

1. Відкрийте `data/films.json`.
2. Додайте, змініть або видаліть записи всередині масиву `films`. Якщо оновили фактичні дані, змініть також дату `built` на початку файлу.
3. У терміналі з кореня проєкту виконайте:

   ```bash
   node scripts/build-catalog.mjs
   ```

4. Відкрийте `index.html` і перевірте результат.

Команда перевіряє обов'язкові поля, типи значень, десятиліття та дублікати IMDb ID. Якщо все гаразд, вона створює:

- `films.js` — файл, який читає сайт; він працює навіть коли `index.html` відкрито напряму з диска;
- `films.csv` — актуальну табличну копію для Excel або Numbers.

`films.js` і `films.csv` не треба редагувати вручну: вони завжди відновлюються з `films.json`.

## Шаблон одного фільму

```json
{
  "imdb_id": "tt1234567",
  "title": "Original title",
  "title_uk": "Українська назва",
  "year": 2025,
  "rating": 7.8,
  "votes": 12000,
  "genres": ["Biography", "Drama"],
  "country": "США",
  "country_main": "США",
  "region": "США",
  "language": "англ.",
  "theme": "Соціальна драма",
  "who_what": "Коротко: про кого або про яку подію фільм.",
  "basis": "реальна історія",
  "note": null,
  "thriller_flag": false,
  "decade": "2020-ті",
  "desc": "Повний опис фільму."
}
```

Фільтри за роками, темами, регіонами та достовірністю формуються автоматично з цих полів. Нова назва в `theme` або `region` автоматично стане новим пунктом відповідного фільтра. Для нового виду фільтра, якого ще немає серед полів, знадобиться один раз додати його відображення до інтерфейсу.

Каталог фільмів не записується в Supabase і не витрачає її ліміти. У Supabase залишаються тільки входи користувачів, персональні позначки, оцінки та коментарі.

## Скіни сайту

Палітри зберігаються окремо у `skins.js`. Щоб додати новий скін, скопіюйте один об'єкт у масиві `SKINS`, задайте унікальні `id`, `label` і кольори в `palette`. Він автоматично з'явиться у перемикачі «Скін» — HTML, каталог та Supabase змінювати не треба.
